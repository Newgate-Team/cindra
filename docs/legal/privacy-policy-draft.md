# Политика конфиденциальности Cindra — черновик

> **Это черновик для внутреннего ревью, не финальный юридический документ.** Перед публикацией должен быть проверен юристом на соответствие применимым юрисдикциям (см. открытый вопрос о юрисдикции пользователей — [docs/spec.md](../spec.md) §9). Плейсхолдеры вида `[...]` — заполнить перед публикацией.

**Последнее обновление:** [дата публикации]

## 1. Кто мы

Cindra ([юридическое название компании], [юрисдикция регистрации]) — сервис для генерации и публикации контента в социальных сетях с помощью ИИ. Контакт по вопросам конфиденциальности: `[privacy@cindra.example]`.

## 2. Какие данные мы собираем

| Категория | Что именно | Зачем |
|---|---|---|
| Аккаунт | Email, хэш пароля (никогда не пароль в открытом виде) | Регистрация и вход |
| Профиль | Роль (агентство/соло), тариф подписки | Персонализация лимитов и функций |
| Подключённые соцсети | Access/refresh-токены (зашифрованы, см. §4), ID подключённого канала/аккаунта, отображаемое имя | Публикация контента от вашего имени по вашему запросу |
| Сгенерированный контент | Промпты, тексты, ссылки на изображения, история задач генерации | Формирование ленты публикаций, история для пользователя |
| Публикации | Текст, статус публикации, ID сообщения на площадке, ошибки | Отображение статуса, повторные попытки при сбоях |
| Использование | Количество генераций/публикаций за период | Учёт лимитов тарифа |

Мы **не собираем** и не храним платёжные данные напрямую — оплата обрабатывается через App Store/Google Play (см. открытый вопрос о провайдере — docs/spec.md §9).

## 3. Кому мы передаём данные

- **Google (Gemini API)** — тема и бренд-гайд передаются для генерации текста. См. [политику конфиденциальности Google](https://policies.google.com/privacy).
- **Telegram / Meta (Instagram)** — при публикации мы отправляем сгенерированный контент через официальные API этих платформ от имени подключённого вами аккаунта.
- **[Провайдер генерации изображений/видео]** — будет указан здесь после выбора провайдера (см. гейт-тикет CIN-50).
- Мы не продаём персональные данные третьим лицам.

## 4. Как мы храним и защищаем данные

- Пароли — хэшируются (Argon2), никогда не хранятся в открытом виде.
- OAuth-токены соцсетей — шифруются at rest (Fernet/AES) перед сохранением в базе данных.
- Доступ к данным пользователя изолирован на уровне базы данных (row-level access по user_id) — один пользователь не может увидеть данные другого через API.
- Секреты приложения (ключи API, ключи шифрования) хранятся отдельно от кода, не коммитятся в репозиторий.

## 5. Сколько мы храним данные

- Данные аккаунта и история — пока аккаунт активен.
- При удалении аккаунта: `[описать срок и процесс удаления — заполнить перед публикацией]`.
- Подключённые соцаккаунты можно отключить в любой момент — токен удаляется из БД сразу.

## 6. Ваши права

В зависимости от вашей юрисдикции вы можете иметь право на доступ, исправление, удаление ваших данных, а также на перенос данных. Обращайтесь по `[privacy@cindra.example]`.

`[Если пользователи из ЕС/EEA — добавить раздел GDPR: правовое основание обработки, право на возражение, DPO. Если пользователи из Калифорнии — раздел CCPA. Зависит от целевой юрисдикции, см. открытый вопрос в docs/spec.md §9.]`

## 7. Изменения политики

Мы можем обновлять эту политику. О существенных изменениях уведомим по email или в приложении.
