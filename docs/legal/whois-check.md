## Вывод

Из трёх целевых зон свободна только `.io`. `.com` и `.ai` заняты — `.com` явно несвязан (домену 26 лет), `.ai` требует ручной проверки на предмет конфликта (см. ниже).

## Что осталось сделать вручную

1. Открыть `cindra.ai` в браузере — проверить, не занят ли активным сайтом/продуктом, который может создать коллизию бренда.
2. Если `.com`/`.ai` реально нужны для бренда (а не только `.io`) — обратиться к текущим владельцам через регистратора (WHOIS contact / брокерский сервис) для покупки, или подобрать альтернативное имя.
3. Зарегистрировать `cindra.io` напрямую через регистратора (не через агента) — это финансовая операция с вводом платёжных данных.
