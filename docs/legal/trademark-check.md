# Проверка товарного знака «Cindra»

Попытка предпринята 2026-07-31.

## Результат

**Автоматическая проверка не удалась технически** — все основные базы товарных знаков блокируют программный доступ:

| База | Что произошло |
|---|---|
| USPTO TESS / tmsearch.uspto.gov | Современный поиск USPTO — JS-приложение (SPA), не отдаёт результаты без выполнения JS в браузере; открытого REST API не нашёл |
| Justia Trademarks | Cloudflare bot-challenge (HTTP 403 / JS-челлендж) |
| WIPO Global Brand Database | Редирект через JS (`XMLHttpRequest` + `localStorage`) перед показом результатов, не отдаёт данные при простом HTTP-запросе |

Общий веб-поиск по «Cindra trademark USPTO software» не выявил очевидных существующих регистраций в сфере ПО/IT-услуг (класс 9/42), но это **не замена настоящей проверке** — обычный веб-поиск не индексирует товарные знаки надёжно.

## Что осталось сделать вручную

1. Выполнить поиск напрямую в [USPTO TESS](https://tmsearch.uspto.gov/) по классам 9 (ПО) и 42 (IT-услуги/SaaS) — через браузер, руками.
2. Аналогично — [Роспатент, открытые реестры ФИПС](https://www.fips.ru/) для российской юрисдикции.
3. Если бюджет позволяет — заказать профессиональный clearance search у патентного поверенного перед регистрацией бренда: автоматизированные бесплатные базы (в т.ч. те, что выше) не покрывают все юрисдикции и не ловят фонетически схожие знаки.
