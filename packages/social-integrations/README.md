# packages/social-integrations

Адаптеры публикации по одному модулю на платформу: OAuth-подключение, публикация, обработка rate limits и ошибок API, статус публикации.

MVP: Telegram ([CIN-5](https://dalmonded.atlassian.net/browse/CIN-5)), Instagram ([CIN-6](https://dalmonded.atlassian.net/browse/CIN-6)).
